# Mira Wan 2.2 — Private Generation Space

This Space is the dedicated image-to-video backend for Mira Studio. It is designed to be copied into your own Hugging Face Space so Mira does not depend on another owner's Space.

The generator uses the Wan 2.2 I2V Diffusers model and Gradio. Set this Space to ZeroGPU when creating it.

Important: owning the Space removes the dependency on another owner's Space, but Hugging Face ZeroGPU usage limits still apply to the account running the Space.
